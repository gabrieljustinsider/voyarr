Help & Guide

Set up instructions ▼
1. Go to the Settings tab.
2. Add your Voyarr server URL and API key.
3. Click "Add & Test Server".
How to get an API key ▼
In the Voyarr application, go to Settings > API Keys, and generate a new Master API key, or copy your existing one.
How to use Lens ▼
Navigate to a supported site. Use the "Remote Map" tab to map selectors or the "Lens" tab to scan the page for subscription details.
